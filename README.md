# 电商经营异常诊断与增长优化系统

**用途：** 面向电商数据运营岗位的作品集演示。所有数据均为合成模拟数据，不属于真实公司数据。

## 功能
- 销售额、访问量、订单量、支付转化率、广告 ROAS 总览
- 日趋势和前后周期经营指标对比
- 品类销售额、估算利润、退货率与折扣分析
- 商品运营标签和 CSV 导出
- 分渠道排查、漏斗优化、广告效率及实验验证建议

## 运行
Python 3.10+：
```bash
pip install -r requirements.txt
streamlit run app.py
```
请确保三个 CSV/py 文件在同一文件夹。

## 面试介绍
“我设计了一个电商经营异常诊断项目，模拟运营团队面对销售额波动时的分析过程。先建立销售额、流量、支付转化率、客单价、广告效率、退款率和估算毛利指标体系，再通过前后周期对比定位异常线索；随后下钻到品类和商品层面，区分利润优先推广、高销售低利润和高退货风险商品，最后提出分渠道排查、漏斗优化和实验验证建议。当前使用合成数据演示完整流程，后续会接入真实订单和渠道数据，完善归因与利润口径。”

## 指标口径提醒
销售额可近似拆解为流量 × 支付转化率 × 客单价（确保口径一致）。真实 ROAS 应使用广告归因销售额；真实利润应纳入商品成本、平台费用、物流履约、优惠承担方和退货损失。
